## `Env`

```swift
final class Env
```

What the app shares with the extension. The only ways an extension wakes up are here: `every`, `watch` and `on`. All three are cancelled by the app while the atom is not on a showing bar, so an extension that uses only these costs nothing at rest. A raw `Timer`, `DispatchSource` or `Thread` in an extension is a validation error.
