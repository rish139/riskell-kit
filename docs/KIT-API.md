## `ManagerHook`

```swift
protocol ManagerHook : AnyObject
```

A behaviour that adds the window manager's own commands to what riskell sends it. For each event named in `events`, riskell calls `commands(for:in:)` on its window-manager queue and puts what it returns at the front of the next request it sends, together with its own queries. That keeps it to one request, so the manager lays the windows out once. The call must return at once: no waiting and no input or output. Only the AeroSpace backend calls hooks.

| member | |
|---|---|
| `var bindingMode: String? { get }` | The binding mode of the manager that this hook's keys are bound in, or nil when it has none. riskell puts the manager into that mode while the hook runs and back into `main` when it stops (or riskell quits), so the keys that do nothing without the hook (bound to `true`, say, for the hook to act on) exist only in that mode and `main` keeps the plain ones. A mode the manager does not have is reported once and left alone. |
| `func commands(for event: ManagerEvent, in state: ManagerState) -> [ManagerCommand]` | The commands to send for `event`, given what riskell knows (`state`). Empty: nothing to send. |
| `var events: Set<String> { get }` | The names of the events it wants (`ManagerEvent.name`). No other event reaches it. |
| `func needsFrames(for event: ManagerEvent) -> Bool` | True when `ManagedWindow.frame` should be filled in for `event`. Reading frames costs one call to the window server, so riskell makes it only when a hook says so for the event at hand, and the frames are the live ones, not the ones of the last query. The default is false. |
| `func wants(_ event: ManagerEvent) -> Bool` | True when the hook wants this event. It is asked after the name is found in `events` and before riskell builds the state for the event, which costs a call to the window server: a hook that acts on only a few of the variants of a frequent event (a few key bindings among all of them) answers here and is left out of the rest, so they cost nothing for it. The default is true. |
